# GATE CS — 6-Phase Study Plan / Timetable

**Cycle:** LEARN → PRACTICE → PYQ → TEST → REVISE. Do not move phases until the current phase's PYQs are understood.

## PHASE 1 — Mathematical Foundation (Weeks 1–4)
Discrete Math → Linear Algebra → Probability & Statistics → Calculus basics. Solve Engineering Mathematics PYQs 2018–2026 topic-wise.

## PHASE 2 — C Programming + Core Data Structures (Weeks 5–8)
C pointers, arrays, recursion, dynamic memory, structures → stacks/queues/linked lists → trees, BST, AVL, heap, graphs. Solve P&DS PYQs 2018–2026.

## PHASE 3 — Algorithms (Weeks 9–11)
Sorting + asymptotics + Master theorem → BFS/DFS/Dijkstra/Bellman-Ford/Floyd/Prim/Kruskal → dynamic programming (LCS, knapsack, matrix chain, coin change) + divide-and-conquer + greedy. Solve and repeat graph/DP PYQs.

## PHASE 4 — Core Systems (Weeks 12–16)
Digital Logic → COA cache/memory/pipeline/hazards → OS processes, scheduling, paging/TLB, page replacement, synchronization, deadlocks, file systems. Immediate topic-wise PYQs.

## PHASE 5 — Theory + DBMS + Networks + Compiler (Weeks 17–22)
TOC regular languages → CFG/PDA → TM → decidability; DBMS ER → relational algebra → SQL → normalization → transactions → B+ trees; CN OSI/TCP-IP → MAC/error control → IP/CIDR/routing → TCP → application layer; Compiler lexical/parsing/SDT/code generation/optimization.

## PHASE 6 — Integration, Full Papers, Mock Tests (Weeks 23–30)
Complete remaining revision, then full-paper simulations, mixed-topic tests, mistake logs and spaced repetition. Use one full paper every two weeks as the regular baseline, increasing frequency near the exam.

## Daily Timetable Rule
Study one concept block → solve its PYQs within 24–48h → log mistakes → revisit weak questions on a spaced schedule.
