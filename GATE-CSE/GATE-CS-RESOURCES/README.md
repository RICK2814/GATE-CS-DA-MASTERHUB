# GATE CSE — Advanced Resource Hub

## What This Folder Contains

This is the **learning layer** of the GATE CSE workspace. Each subject page is no longer just a list of links; it is an expanded study sheet containing:

1. **Subject profile** — strategic context from the Master Strategy source.
2. **Core resource stack** — playlist, one-shot/revision, PYQ platform and notes where supplied.
3. **Topic-wise YouTube lecture table** — every subtopic explicitly mapped to its source lecture.
4. **PYQ link** — the corresponding question-practice entry for the subject.
5. **Notes link** — reference material where the source provides one.
6. **Study sequence** — how to move from lecture to practice to PYQ.
7. **Completion checklist** — a concrete definition of “topic completed”.
