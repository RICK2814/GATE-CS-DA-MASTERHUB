# GATE CS — Subject-wise Tier Analysis

## TIER 1 — MUST MASTER FIRST
1. **Programming & Data Structures** — C programming, pointers/recursion, trees, BST/AVL, heaps, graphs.
2. **Algorithms** — graph algorithms, dynamic programming, divide & conquer, complexity analysis.
3. **Operating Systems** — CPU scheduling, memory management, synchronization, deadlocks, file systems.
4. **Computer Networks** — IP/CIDR, subnetting, TCP, routing, application layer.
5. **Discrete Mathematics** — graph theory, logic, combinatorics, sets/relations.

## TIER 2 — HIGH PRIORITY
6. **Theory of Computation** — DFA/NFA, regular expressions, CFG/PDA, Turing machines, decidability.
7. **DBMS** — SQL, functional dependencies, normalization, transactions, indexing.
8. **Computer Organization & Architecture** — cache, pipelining, hazards, memory hierarchy.
9. **Engineering Mathematics** — linear algebra + probability/statistics.
10. **Digital Logic** — Boolean algebra, K-maps, sequential circuits.

## TIER 3 — MEDIUM PRIORITY
11. **Compiler Design** — parsing, FIRST/FOLLOW, syntax-directed translation, code generation/optimization.
12. **Calculus** — limits, differentiation, integration, maxima/minima, mean value theorem.

## GATE CS Structural Foundation
The master guide uses the standard 65-question, 100-mark, 3-hour structure with General Aptitude and Engineering Mathematics as fixed components, and emphasizes conceptual preparation for MCQ/MSQ/NAT formats.

## Core Topic Dependency
**Math + Discrete Math → P&DS → Algorithms → Systems (OS/COA/CN) → TOC/DBMS/Compiler → full-paper integration.**
