# GATE-CS-DA-MASTERHUB

GATE 2027 CS & DA Master Hub — organized into two complete preparation workspaces. The website HTML is intentionally not stored in this repository.

## Main Workspaces

| Track | Open | Includes |
|---|---|---|
| GATE CSE | [Open GATE-CSE](GATE-CSE/) | CS Analysis, Year-Wise Tables, Priority Lists, Study Plan/Timetable, PYQ Strategy, Master Table, and detailed CS Resources |
| GATE DA | [Open GATE-DA](GATE-DA/) | DA Analysis, Year-Wise Tables, Priority Lists, Study Plan/Timetable, PYQ Strategy, Master Table, Syllabus/Planning Tracker, and detailed DA Resources |

## Master Preparation Flow

**Analysis → Priority Lists → Study Plan / Timetable → Topic Resources → PYQs → Master Table → Revision**

## Resource Model

The resource hubs keep the source guide's resource types together: **YouTube lectures, playlists, one-shot/revision videos, topic-wise lectures, PYQs, notes/PDFs, practice links, and interactive resources**.
