# 🧠 Master Preparation Philosophy

The whole repository is built around one repeatable pipeline:

```text
ANALYSE
   ↓
PRIORITISE
   ↓
PLAN
   ↓
LEARN
   ↓
PRACTICE
   ↓
PYQ
   ↓
TEST
   ↓
REVIEW
   ↓
RE-SOLVE
   ↓
REVISE
```

### 01 — Analyse

Understand the syllabus, subject relationships, historical patterns and topic families before spending large amounts of study time.

### 02 — Prioritise

Convert broad subjects into smaller actionable units. High-recurrence, numerical-heavy and conceptually central areas can then be scheduled deliberately.

### 03 — Plan

Turn the priority list into a timetable, phase plan or tracker instead of maintaining a loose list of topics.

### 04 — Learn

Use a combination of:

- full lecture series
- playlists
- one-shot videos
- topic-specific lectures
- notes / PDFs
- interactive visual resources

### 05 — Practice

A topic should not remain “theoretical”. Practice should follow concept acquisition.

### 06 — PYQ

Move from:

**topic-wise PYQs → mixed PYQs → year-wise papers → full-paper simulation**

### 07 — Test

Measure more than marks:

- accuracy
- time
- question selection
- conceptual gaps
- careless errors
- repeated mistake patterns

### 08 — Review

Every wrong or guessed question should become a learning asset.

### 09 — Re-solve

Return to difficult questions after a gap rather than immediately looking at the answer again.

### 10 — Revise

Use the Master Table, short notes, formula resources, one-shots and previously incorrect PYQs for final reinforcement.

The repository uses multiple resource types because different stages of preparation need different learning formats.

| Type | What It Is For | Best Stage |
|---|---|---|
| **Full Lecture** | Deep first-time learning | First study |
| **Playlist** | Sequential chapter coverage | First study |
| **One-Shot** | Compact coverage | First-pass / revision |
| **Topic Lecture** | Weak concept correction | Gap filling |
| **Notes / PDF** | Reference + recall | During + after study |

# 🧪 PYQ System

## Level 1 — Topic-Wise PYQ

After completing one topic, solve its relevant PYQs.

**Objective:** determine whether the concept can be transferred into exam-style problems.

## Level 2 — Mixed-Topic PYQ

Mix related concepts so that you cannot rely on topic clues.

**Objective:** improve question identification.

## Level 3 — Year-Wise Paper

Attempt a complete paper in exam conditions.

**Objective:** evaluate selection, timing and endurance.

## Level 4 — Error-Only Revision

Create a pool of:

- wrong questions
- guessed questions
- slow questions
- repeated mistakes

**Objective:** convert mistakes into future marks.

## Level 5 — Re-Solve

Reattempt without looking at the original solution.

**Objective:** test whether the concept has actually been retained.

# 📊 Progress Tracking System

A robust preparation tracker should distinguish between:

| Status | Meaning |
|---|---|
| **Not Started** | Topic not yet touched |
| **Learning** | Lecture / concept phase |
| **Practicing** | Basic problems in progress |
| **PYQ Done** | Relevant PYQs attempted |
| **Weak** | Significant mistakes remain |
| **Revised** | At least one structured revision completed |
| **Strong** | Can solve standard questions reliably |
| **Tested** | Topic has appeared in a timed test |

### Important rule

**“Video watched” ≠ “topic completed”.**

Completion should require a combination of understanding, practice and PYQ exposure.

# 📝 Recommended Error Log

For every meaningful mistake, record:

| Field | Record |
|---|---|
| Subject | Exact subject |
| Topic | Exact concept |
| Question | PYQ / practice reference |
| Error Type | Concept / calculation / interpretation / careless |
| Correct Idea | What should have been done |
| Why I Missed It | Actual reason |
| Re-Solve Date | Next attempt |
| Final Status | Fixed / needs revision |

# 🔁 Revision Architecture

## First Revision

Review shortly after completing the topic.

## Second Revision

Return after a longer gap and solve selected questions again.

## Third Revision

Use only compressed material:

- formulas
- short notes
- one-shot
- wrong PYQs
- master table

## Final Revision

Prioritize:

**weak topics → frequent mistakes → high-practice numerical areas → high-value concepts → formula recall**

# 🎯 Subject Study Template

Use the same process for every subject:

```text
1. Check syllabus
2. Read analysis
3. Check priority list
4. Select lecture / playlist
5. Study concept
6. Make / review notes
7. Practice basic questions
8. Solve PYQs
9. Record mistakes
10. Re-solve mistakes
11. Attempt timed questions
12. Update tracker
13. Update Master Table
14. Revise later
```
