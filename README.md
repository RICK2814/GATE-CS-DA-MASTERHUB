# 🎯 Master Preparation System

The repository follows a complete loop instead of acting as a simple link collection:

**ANALYSE → PRIORITISE → PLAN → LEARN → PRACTICE → PYQ → TEST → REVIEW → REVISE**

### 01 — Analyse
Understand the subject structure, historical PYQ trends and recurring concepts.

### 02 — Prioritise
Use the priority lists and master tables to identify the topics that deserve early attention.

### 03 — Plan
Convert priorities into a realistic study plan and timetable.

### 04 — Learn
Use the curated YouTube lectures, playlists, one-shots, topic-wise lectures and notes.

### 05 — Practice
Solve topic-specific questions immediately after learning.

### 06 — PYQ
Move from topic-wise PYQs to year-wise full-paper simulation.

### 07 — Test
Track accuracy, time, question type and repeated mistakes.

### 08 — Review
Maintain an error log and revisit weak areas.

### 09 — Revise
Use master tables, notes, formula resources, one-shots and targeted PYQ sets.

# 🧪 PYQ Practice Stack

### Layer 1 — Topic PYQ
Complete a topic and immediately solve its relevant PYQs.

### Layer 2 — Mixed PYQ
Combine related subtopics to remove pattern dependency.

### Layer 3 — Year-Wise Paper
Attempt full papers under realistic time limits.

### Layer 4 — Error Re-Solve
Revisit wrong, guessed and slow questions.

### Layer 5 — Final Revision
Use the Master Table + notes + targeted PYQ sets.

# 🔄 Repository Philosophy

This is **not intended to be only a collection of links**.

It is structured as a preparation system:

> **Understand → Organize → Learn → Practice → Solve PYQs → Analyse → Revise → Test**

The detailed resource pages are the learning layer; the strategy pages are the decision layer; the PYQ layer is the exam-pattern layer; and the Master Table is the final revision layer.
