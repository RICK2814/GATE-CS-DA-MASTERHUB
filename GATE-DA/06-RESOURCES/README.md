# GATE DA — Advanced Resource Hub

## What This Folder Contains

Every DA subject now has an expanded resource page rather than a simple notes link. The pages combine:

- subject-level strategic context
- playlist / primary course
- one-shot or revision resource
- subject-specific PYQ practice
- notes / Drive resource where available
- **topic-wise YouTube lecture table**
- a recommended study sequence
- a topic completion checklist
