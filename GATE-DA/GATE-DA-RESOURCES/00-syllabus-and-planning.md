## Recommended Planning Workflow

**Official Syllabus → 100-Day Tracker → Subject Priority → Weekly Plan → Daily Topic → PYQ → Error Log → Revision**

## Tracker Discipline

Do not mark a topic complete only because a lecture was watched. A robust completion state should include:

- concept coverage
- notes/reference review
- basic practice
- topic-wise PYQ exposure
- wrong/guessed question review
- later revision
