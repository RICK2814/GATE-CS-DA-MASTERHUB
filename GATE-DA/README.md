# 04 — Study Plan & Timetable

## Four Main Phases

### Phase 1 — Mathematical Foundation
**Probability & Statistics + Linear Algebra**

Build the mathematical language needed for later ML and AI work.

### Phase 2 — Programming + Calculus
**Python + DSA + Algorithms + Calculus/Optimization**

Develop programming fluency and mathematical problem-solving.

### Phase 3 — ML + Database
**Machine Learning + Database Management & Warehousing**

Move into core technical DA subjects and combine conceptual learning with problem solving.

### Phase 4 — AI + Full-Paper Integration
**Artificial Intelligence + full-paper practice + mixed revision**

Finish the technical cycle and gradually move toward timed exam simulation.

### Repeatable daily cycle

**Concept → Lecture → Notes → Topic Practice → PYQ → Error Log → Re-solve**

**Open:** [Study Plan & Timetable](04-study-plan-and-timetable.md)

# 05 — PYQ Strategy

### Recommended DA PYQ cycle

**Study topic → solve topic PYQs → inspect reasoning → classify errors → re-solve → mix with another topic → attempt full paper**

### Error classification

- Concept error
- Formula error
- Calculation error
- Interpretation error
- Time pressure
- Question selection
- Careless mistake

### Final stage

Wrong and guessed questions become a dedicated revision pool instead of being discarded after checking the answer.

**Open:** [PYQ Strategy](05-pyq-strategy.md)
